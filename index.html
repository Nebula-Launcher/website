Nebula

The lightweight Minecraft launcher family.

From the minimalist terminal experience of Nebula Nano to the lightweight GUI of Nebula Lite — every edition is built to stay fast, open, and free. Nebula Hero (full GUI) is currently a proof of concept.

Terminal

Nebula Nano

Minimal. Fast. Terminal.

The smallest member of the Nebula family.

 # nebula-nano
$ nebula version 1.21.4
$ nebula memory 4G
$ nebula user WhyFle
$ nebula dir ~/minecraft
$ nebula launch
  • 🖥️ Terminal interface
  • ⚡ Extremely lightweight
  • 📂 Version management
  • 💾 RAM configuration
  • 👤 Username configuration
  • 📁 Custom Minecraft directory
  • 🔓 Offline (cracked) support

No mods. No skins. No GUI. Just Minecraft.
