# Nebula Website

The official website for the Nebula Minecraft launcher family.

## Features

- Landing page with animated stars and nebula effects
- Dedicated pages for Nebula and Nebula Nano
- Download page with platform options
- Wiki system with JSON database
- Forum with posts and replies
- User authentication (localStorage)

## Hosting

This site is hosted on GitHub Pages.

## Local Development

Simply open `index.html` in your browser - no build step required.

## Deploy

Just push to the `main` branch and GitHub Pages will auto-deploy.
